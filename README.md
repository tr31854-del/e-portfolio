# 🌐 E-Portfolio | นางสาว กวิสรา กาวิน (Kawisara Kawin)

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) และ Statement of Purpose ของ **นางสาว กวิสรา กาวิน** นักเรียนชั้นมัธยมศึกษาปีที่ 6 แผนการเรียนศิลป์-ภาษาญี่ปุ่น โรงเรียนธัญรัตน์ พัฒนาขึ้นเพื่อรวบรวมประวัติส่วนตัว แรงบันดาลใจในการศึกษาต่อคณะอักษรศาสตร์ ผลงาน และกิจกรรมต่าง ๆ ในรูปแบบที่ทันสมัยและเข้าถึงง่ายผ่านอุปกรณ์ทุกขนาด[cite: 1]

---

## ✨ คุณสมบัติเด่น (Features)

- **โครงสร้างครบถ้วน 4 ส่วนหลัก:**
  1. **หน้าแรก (Home):** แนะนำตัวตนเบื้องต้น พร้อมปุ่มเข้าถึงผลงานและบัญชี GitHub ได้ทันที
  2. **แนะนำตัว (Statement of Purpose):** ถ่ายทอดแรงบันดาลใจด้านภาษา เส้นทางสู่อาชีพ "ล่าม" และเป้าหมายการศึกษาต่อในคณะอักษรศาสตร์[cite: 1]
  3. **ผลงาน (Portfolio):** การ์ดแสดงผลงานและโครงงานดิจิทัลพร้อมคำอธิบายและลิงก์เชื่อมต่อไปยัง Repository
  4. **กิจกรรม (Activities):** ไทม์ไลน์แสดงประสบการณ์การเข้าร่วมกิจกรรมทางภาษาและเทคโนโลยี
- **ดีไซน์ทันสมัย (Blue & White Theme):** ใช้โทนสีน้ำเงิน-ขาวที่ดูสะอาดตา เป็นมืออาชีพ และอ่านง่าย
- **รองรับภาษาไทยสมบูรณ์:** ใช้ฟอนต์ **Prompt** จาก Google Fonts เพื่อความสวยงามและชัดเจนในการอ่าน
- **Responsive Design:** รองรับการแสดงผลทั้งบนหน้าจอคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ พร้อมเมนูแบบ Hamburger และระบบ Scroll Spy
- **Single-File Architecture:** เขียนโค้ดทั้งหมด (HTML, CSS, JavaScript) ไว้ในไฟล์ `index.html` เพียงไฟล์เดียว ไม่ต้องติดตั้ง Framework หรือ Library เพิ่มเติม

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **HTML5** — โครงสร้างหลักของเว็บไซต์
- **CSS3** — การจัดวางเลย์เอาต์ด้วย Flexbox & Grid, ตัวแปรสี (CSS Variables) และการออกแบบ Responsive
- **JavaScript (Vanilla JS)** — ควบคุมเมนูนำทางบนมือถือและไฮไลต์แถบเมนูอัตโนมัติตามตำแหน่งการเลื่อนหน้าจอ
- **Google Fonts** — ฟอนต์ `Prompt`
